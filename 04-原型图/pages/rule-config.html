计算公式说明

总分 = Σ(因素归一化得分 × 权重)
  position = 敏感区? 1.0 : 0.6
  type     = 非法排放 1.0 / 水色异常 0.8 / 岸线垃圾 0.6 ...
  count    = min(近90天次数 / 5, 1)
  duration = min(平均处置时长 / 60h, 1)
  review   = 1 - 通过率
  quality  = 水质恶化程度(0~1)
等级：总分 ≥ 75 高；≥ 50 中；否则低
推荐：高 → 纳入专项治理；中 → 加密巡查；低 → 常规管理
计算过程逐项落库（river_patrol_score），保存输入快照、规则版本、各项得分与生成时间，保证可追溯。
