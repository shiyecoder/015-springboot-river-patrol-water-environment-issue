# 组件规范

## 按钮
| 类型 | 高 | 内边距 | 圆角 | 配色 |
|---|---|---|---|---|
| 主按钮 | 32px | 0 16px | 4px | 底 #15344A，字 #fff，hover #1C425C |
| 次按钮 | 32px | 0 16px | 4px | 白底，描边 #DCE5E8，字 #1F2D33 |
| 文字按钮 | 32px | 0 4px | — | 字 #2D5B6B |
| 危险按钮 | 32px | 0 16px | 4px | 白底，描边 #B03035，字 #B03035 |
| 小号 | 26px | 0 10px | 4px | 表格行内操作用 |

行内最多「查看 + 2 个高频操作」，其余进「更多」菜单。

## 表单
- 标签右对齐，宽 100–120px，必填前置红色 `*`
- 输入框高 32px，内边距 0 10px，描边 #DCE5E8，聚焦 #237A8B + 2px 外发光
- 错误态描边 #B03035，下方 12px 红字说明
- 下拉框宽 180–240px；日期范围用日期选择器，人员/组织/字典用对应选择器，不用纯文本框

## 表格
- 表头背景 #F3F7F8，字 #5F7078，13px/500，下边框 1px #DCE5E8
- 行高 44px，斑马纹关闭，hover #F7FAFA
- 单元格 13px，垂直居中，左对齐；数字列右对齐 + tabular-nums
- 分页居右：总数 + 每页 10/20/50 + 页码，切换筛选后回第 1 页

## 状态标签
高 22px，内边距 0 8px，圆角 3px，12px 字，浅底深字：
待确认 #E8F1F3/#237A8B ｜ 待派单 #E6EDF1/#2D5B6B ｜ 处置中 #E4EBEF/#15344A ｜ 待复查 #F6EFDF/#8A6D3B ｜ 已关闭 #E4F0E9/#2D7A58 ｜ 无效上报 #EDEFF0/#8B9AA1 ｜ 逾期 #F7E6E7/#B03035

## 卡片
白底，1px #DCE5E8，圆角 6px，内边距 16px，标题 15px/600 + 右上角操作区。

## 指标卡（首页）
宽自适应，高 88px：左上 12px 灰标签，左下 26px 主色数字（tabular-nums）+ 单位，右下同比变化（升红降绿按业务语义，环境类指标"下降为好"用绿色）。

## 弹窗 / 抽屉
- 弹窗宽 480/640px，圆角 8px，标题栏 16px，底部右对齐按钮
- 抽屉宽 520px，右侧滑入，顶部展示单据摘要（编号 + 状态 + 责任人），底部固定操作区
- 危险操作二次确认，确认文案包含对象名称

## 时间轴
左侧 2px 竖线 #DCE5E8，节点 8px 圆点（当前节点 #237A8B 实心，历史 #8B9AA1 空心），右侧事件标题 14px/500 + 时间 12px 灰 + 操作人 + 原因。

## 空状态
居中插图 96px + 主文案「当前筛选条件下无记录」+ 次文案「清空筛选条件或新建巡查问题单」+ 主按钮。

## 加载
超过 300ms 显示表格骨架（3 行灰条）或局部 loading，禁止整页白屏。
