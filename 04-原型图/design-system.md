# 设计系统 — 河道巡查与水环境问题处置系统

## 设计方向
"公共服务蓝"专业业务系统。以数据可读性、操作效率、状态辨识为第一原则。不使用巨幅英文口号、装饰光效、悬浮球、过度渐变和大面积插画。卡片圆角 6–8px，阴影仅用于抽屉与弹窗。正文使用系统中文字体，数字列启用等宽数字（`font-variant-numeric: tabular-nums`）。

## 色彩

| 用途 | 色值 | 用法 |
|---|---|---|
| 主色 primary | `#15344A` | 顶栏、主按钮、当前菜单、关键数字 |
| 辅助色 secondary | `#237A8B` | 次级按钮、筛选选中态、普通图表系列 |
| 页面背景 bg | `#F3F7F8` | 主内容区背景（表格/表单为白色容器） |
| 强调色 accent | `#2D5B6B` | 链接、信息提示、图表对比系列 |
| 成功 success | `#2D7A58` | 已完成、已通过、正常 |
| 危险 danger | `#B03035` | 驳回、超时、异常、删除确认（仅小面积） |
| 边框 border | `#DCE5E8` | 表格线、卡片描边 |
| 主文字 | `#1F2D33` | 标题与正文 |
| 次文字 | `#5F7078` | 辅助说明、表头 |
| 弱文字 | `#8B9AA1` | 占位、时间戳 |

状态不只用颜色表达，必须同时有中文标签或图标。

## 字体阶梯
- 页面标题 20px / 600
- 卡片标题 15px / 600
- 正文 14px / 400，行高 1.6
- 表格 13px，表头 13px / 500
- 辅助 12px
- 数字列 14px，tabular-nums

## 圆角与阴影
- 卡片 6px，按钮 4px，标签 3px，输入框 4px，抽屉 8px（仅左侧圆角）
- 卡片无阴影，1px 边框；抽屉 `0 8px 24px rgba(21,52,74,.18)`；弹窗 `0 12px 32px rgba(21,52,74,.22)`

## 布局
- 侧边栏 220px（折叠 64px），顶栏 56px，内容区外边距 24px
- 表单标签 100–120px，单列输入 360–520px
- 搜索下拉 180–240px
- 表格表头不设固定宽度，`min-width` + 横向滚动；编号/状态/日期/操作列 `white-space: nowrap`

## 间距
4 / 8 / 12 / 16 / 24 / 32（基准 4px）

## 角色视觉区分
| 角色 | 首页 | 主色倾向 | 特征 |
|---|---|---|---|
| 管理员 | 后台管理 | #15344A | 全量菜单，系统配置区 |
| 河长办调度员 | 后台管理 | #15344A + 强调 #2D5B6B | 派单台、督办标记 |
| 巡查员 | 移动优先的门户工作台 | #237A8B | 大卡片任务、拍照上报入口 |
| 处置单位人员 | 后台管理（精简菜单） | #237A8B | 整改进度表单 |
| 复查人员 | 后台管理（精简菜单） | #2D5B6B | 复核结论 + 热点评估面板 |

## 图表配色
主 #15344A / 辅 #237A8B / 强调 #2D5B6B / 中性 #8B9AA1 / 成功 #2D7A58 / 危险 #B03035。
同一含义跨页面固定：问题状态 待确认 #237A8B、待派单 #2D5B6B、处置中 #15344A、待复查 #8A6D3B、已关闭 #2D7A58、无效 #8B9AA1。
